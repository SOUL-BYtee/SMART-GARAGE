# Smart Garage System

An IoT-based smart parking solution that automates vehicle access, enhances security, and improves parking efficiency using embedded systems.

---

## Overview

The **Smart Garage System** is designed to provide an automated and intelligent parking experience.
It integrates sensors, microcontrollers, and a mobile interface to monitor and control garage operations in real time.

This project demonstrates how embedded systems and IoT can be applied to solve real-world problems such as parking congestion and manual gate control.

---

## Key Features

*  Automatic vehicle detection using sensors
*  Smart gate control (open/close)
*  Mobile-based user interaction (MIT App Inventor)
*  Real-time system status monitoring
*  Improved security and access management

---

## Technologies & Tools

* **Arduino** (Embedded Controller)
* **IR / Ultrasonic Sensors**
* **Servo Motors** (Gate Control)
* **MIT App Inventor** (Mobile Application)
* **Bluetooth / WiFi Modules** (Communication)

---

## System Workflow

1. A vehicle is detected using IR/Ultrasonic sensors.
2. The sensor sends a signal to the microcontroller.
3. The system processes the input and decides the action.
4. The gate is controlled automatically using a servo motor.
5. The system status is updated on the mobile application.
